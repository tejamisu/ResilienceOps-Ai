Community cards · three directions

Same data, default (pre-demo) state. Each answers "Is this place OK? If not, what's missing?" before anything else.

A · Need gauge

The phone damage gauge (refs 8–9), reused as a need gauge: six fixed segments (water → road) with a tick ruler. A large thin split numeral gives coverage.

Good: very on-style and compact; status is a single shape. Watch: the reader must learn the segment order (W F M S P R), which is a small legend to memorise under stress.

B · Only what's missing

Management by exception. Big coverage number, then chips only for unmet needs: red solid = gap, amber dashed = partly. Met needs fold into "+n met".

Good: fastest to read; zero decoding, every word is a need. Watch: least visual of the three; the cards look different from each other because chip counts vary.

C · Line-art needs Recommended

Six line-art icons in a fixed row (the wireframe language of refs 3, 5, 6). Met needs fade back. Gaps light up red with a tinted fill, partly in amber with a half fill. One plain line names what's missing.

GapPartlyMetUnknown

Good: icons are recognised before words; red items pop out of a quiet row, so you see the gap pattern across all four cards at once. Watch: icons need accessible names and a hover label.
